# Release the reviewed delivery

Delegated workers consume the coordinator's bounded task packet and selected
contracts under [targeted context](../data-model-accelerator/references/agent-context.md).
They do not recursively load the full workflow or repeat intake. The coordinator
retains responsibility for stage gates, approvals and complete coverage.

When coordinating this stage directly, load the sibling [Data Model Accelerator](../data-model-accelerator/SKILL.md),
the [staged workflow](../data-model-accelerator/references/staged-engagement.md) and
the [deployment contract](../data-model-accelerator/references/deployment.md).
Require the complete shared runtime and resume the existing engagement.

Reuse known target choices and authority. Prepare the exact release plan, affected
objects, current evidence and recovery approach before seeking any missing
destination authorization. A `deployment` stage selection routes to the separate
release coordinator; it does not execute a release.

Use the already provisioned policy, runner and external issuers. Do not create
private keys or self-sign. Design-stage review cannot substitute for final artifact
sign-off and destination-specific approval. Host-recorded human review is sufficient
for scoped local candidate generation, but cannot replace this release workflow's
external authority. Run only supported, authorized routes;
retain explicit unsupported provider paths, independent acceptance and recovery
requirements. Unknown submission outcomes must be reconciled before retrying.
