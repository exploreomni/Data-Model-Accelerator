# Tableau source contract

Verified 2026-09-10 against primary sources. This adapter inventories a bounded XML subset and a synthetic workbook. It does not operate Tableau, run workbook SQL, authenticate connections or establish production migration acceptance.

## Format evidence and schema boundary

The official [Tableau Document API repository](https://github.com/tableau/document-api-python/tree/447357fc1ad21945b31c0ed20d69593c13cc7921) supplies native workbook/datasource examples. Its README describes the API as unsupported and does not claim support for creating workbooks from scratch. The fixture uses patterns directly inspected in its [workbook sample](https://github.com/tableau/document-api-python/blob/447357fc1ad21945b31c0ed20d69593c13cc7921/samples/replicate-workbook/sample-superstore.twb), [datasource sample](https://github.com/tableau/document-api-python/blob/447357fc1ad21945b31c0ed20d69593c13cc7921/test/assets/datasource_test.tds), and [nested connection sample](https://github.com/tableau/document-api-python/blob/447357fc1ad21945b31c0ed20d69593c13cc7921/test/assets/filtering.twb): named connections, relation definitions, metadata-record local/remote mappings, calculation formulas, worksheet datasource dependencies, column instances and shelves. No Document API runtime was invoked.

Tableau now separately publishes an [official document-schema baseline](https://github.com/tableau/tableau-document-schemas/tree/f4bce1eb55f0c1c010c0ef826cf531528d5910eb). The pinned file `scripts/schemas/tableau/twb_2026.1.0.xsd` has SHA-256 `8bb236b72c1c388aca92bcd00164f65c0d4f5efeaf225252ce0619d8f631e923`; its publication header is 2026-02-27. The unmodified Apache-2.0 license and provenance are included. The schema confirms `filter context="true"`, `table-calc ordering-type="Field"`, `ordering-field`, and ordered `<order field="..."/>` children. The authored workbook uses the documented version `26.1` and `ManifestByVersion` pattern.

An actual lxml 6.0.2 attempt to compile the pinned official XSD failed before workbook validation: the published file imports the user/XML namespaces without locations and references an unavailable `user:UserAttributes-AG`. No permissive replacement schema was invented. `validate_official_schema(path)` records this as `unavailable_publisher_schema_dependency`, with `validated: false`. Therefore this fixture has **not passed official XSD validation**. The publisher also distinguishes XSD syntax from Tableau semantic opening, excludes connection attributes/formula references from some schema checks, and does not cover TWBX. XML parsing, adapter checks, local replay, official XSD validation and native Tableau opening are separate evidence categories.

## Native artifact and identity contract

`examples/tableau-omni-e2e/input/repo/billing.twb` is the workbook authority. The embedded datasource `federated.billing`, caption `Billing invoices`, uses named connection `tableau-billing-snowflake`. Its declared synthetic server/database/schema are `DMA_TABLEAU_SYNTHETIC` / `DMA_TABLEAU` / `RAW`. These are authored declarations, not authenticated account facts.

`billing.tds` is an exact structural mirror of that embedded datasource, including custom SQL, field definitions, connections and datasource filters. It does not add a second authoritative dataset or workbook. Native column metadata maps nine captioned fields to exact uppercase SQL output names. Calculated-field IDs equal their bracketed captions. The workbook repository ID `tableau-billing-synthetic`, worksheet simple IDs, datasource/field names and file hashes are preserved; they are invented fixture identifiers, not server-issued identity evidence.

`input/packages/billing.twbx` packages the exact TWB, TDS and CSV using fixed member order, timestamps and permissions. It is a packaging test outside `input/repo`, so it is not counted as a second workbook. Tableau distinguishes ordinary workbook/datasource files from packaged workbooks and extracts; an extract is not a substitute for workbook logic. [Tableau file types](https://help.tableau.com/current/pro/desktop/en-us/environ_filesandfolders.htm).

Fixture correction recorded 2026-09-10: the initial authored Segment parameter accidentally used a list restricted to `ALL`, `SMB`, and `Enterprise`, while the predeclared scenario permits other segment strings to produce empty marks. The synthetic TWB now declares `param-domain-type="any"` without members, retaining its `ALL` default. This corrects the source fixture to the existing scenario; the scenario, raw inputs, CSV and oracle were not revised. The TDS bytes are unchanged because this parameter belongs to the workbook's Parameters datasource. The deterministic TWBX and source crosswalk hashes were refreshed. Prior TWB/TWBX bytes remain under `validation/tableau-omni-e2e/iterations/run2/input-snapshot/` so earlier receipts retain their exact source evidence. Native parameter domains remain part of the replay contract; a future list/range change must be interpreted or rejected explicitly.

## Static API and safety

`scripts/tableau_source.py` exposes `inspect_repo(repo) -> dict`. It returns assets/hashes, workbooks, embedded datasources, fields, parameters, worksheets, dashboards, mirrors, scoped edges, gaps and counts. Datasource entries expose the actual `custom_sql`, parsed physical reads/CTEs/joins, connection declarations, exact formulas, raw-column aliases and filters. Worksheet entries preserve native datasource dependencies, column instances, grouping/selected fields, filter member/context evidence, shelves, and table-calculation metadata. Caption duplication never substitutes for scoped identity.

The XML reader uses Python's standard library, rejects DTD/entity declarations, UTF-16/null-byte input, malformed XML and files over 2 MB. It does not execute code. SQLGlot analyzes a single read-only Snowflake query. The optional XSD helper uses lxml without network, DTD loading or entity resolution. Duplicate IDs/mappings, unresolved fields/worksheets, stale worksheet definition copies, mirror drift, missing addressing and unsupported filters become explicit errors. Packages, Hyper/TDE extracts, published sources, Prep, logical relationship semantics, actions, stories, unsupported calculations and dynamic behavior require separate evidence or a specialist.

`inspect_package(path, repo=None)` reads bounded ZIP members in memory and never extracts. It rejects traversal/absolute/Windows paths, normalized duplicate or case-colliding names, symlinks/special files, encryption, unsupported compression, too many members, oversized content and excessive compression ratios. With `repo`, every member must match an existing repository file byte-for-byte. It requires exactly one workbook and reports extract/Prep members as gaps. Safe ZIP reading does not establish Tableau package compatibility.

The present-file inventory cannot detect a wholly absent workbook without an independently captured expected inventory. `static_coverage_complete` reports only coverage of this adapter's declared subset in the supplied files. It is never native runtime validation.

## Preserved behavior and placement

Datasource Boolean filters select posted invoices and the tenant parameter. Each selected worksheet's date predicate carries the native context flag; the segment predicate is an ordinary dimension filter. Tableau documents context filters as preceding dependent filters, and FIXED expressions as preceding ordinary dimension filters. This ordering is essential for Customer Value: changing segment after computing customer FIXED net must not change that fixed value. [Context filters](https://help.tableau.com/current/pro/desktop/en-us/filtering_context.htm), [order of operations](https://help.tableau.com/current/pro/desktop/en-us/order_of_operations.htm).

Revenue Trend retains row Net/Outstanding/Month calculations, guarded ratio of sums and the downstream scenario multiplier. Customer Value selects `MIN([Fixed Customer Net])`; repeating the value across segment marks does not make it additive. Revenue Share retains `WINDOW_SUM` after selected marks. Its explicit addressing is Segment; Invoice Month is the remaining view dimension, so monthly partitioning is an adapter inference grounded in those two native facts, not a fabricated XML partition property. Tableau documents addressing fields and remaining partition dimensions, and that table calculations use the data currently in the visualization. [Table calculations](https://help.tableau.com/current/pro/desktop/en-us/calculations_tablecalculations.htm).

The local replay must interpret these authored formulas and filter memberships. It must not replace unsupported semantics with expected values. All source/warehouse keys include tenant; manual adjustments remain a separately governed input. Native sorting, densification, visual rendering, dashboard actions, scheduling, permissions and source-to-application acceptance remain unqualified.
