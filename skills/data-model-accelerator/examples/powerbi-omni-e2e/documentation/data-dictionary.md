# Power BI billing data dictionary

Specification `powerbi-billing-1.0.0`: **10 models, 64 columns**, derived from candidate raw DDL and model projections. The [canonical JSON](data-dictionary.json) binds exact inventory bytes. Live Snowflake metadata and native runtime behavior remain unverified.

Physical constraints are not inferred from logical tests: DDL/CTAS emits no enforced PK/FK/NOT NULL constraints. Source M row defaults and DAX calculated columns move into gold; context-sensitive measures and disconnected Scenario selection remain downstream. See [semantic mapping](semantic-mapping.md).
