# Validate the selected candidate

Delegated workers consume the coordinator's bounded task packet and selected
contracts under [targeted context](../data-model-accelerator/references/agent-context.md).
They do not recursively load the full workflow or repeat intake. The coordinator
retains responsibility for stage gates, approvals and complete coverage.

When coordinating this stage directly, load the sibling [Data Model Accelerator](../data-model-accelerator/SKILL.md)
and its [staged workflow](../data-model-accelerator/references/staged-engagement.md).
Require the complete shared runtime. Resume the engagement, preserve previous
answers and failed evidence, and check the scoped `validation` stage and task plan.

Use the actual independent analyst role and frozen source-derived expectations.
Inspect relevant grain, fanout, filters, history, data leakage and semantic cases;
keep coverage gaps explicit. Run only checks authorized for the selected project
and environment. A host-recorded human design review permits scoped candidate
work without a signing service; it does not authorize executing repository code.

Use the existing lint, native, benchmark, access and assurance contracts. Record
actual task and output references; reuse only current matching evidence. Local
consistency, native compilation, data accuracy, human acceptance and deployment
remain distinct. Do not alter expectations merely to make a candidate pass.
