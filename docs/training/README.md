# Getting started with the Data Model Accelerator

**Plan the whole migration. Deliver complete business domains.**

Learn what the accelerator does, explore a fictional migration, and prepare your first engagement. This is a reading guide, not an agent or an interactive course. You can learn before installing anything. No SQL knowledge is required to review the examples.

[Download the illustrated PDF](data-model-accelerator-guide.pdf) · [Install the tool](05-install.md) · [Review a delivery](04-review.md)

| Step | You will learn | Read |

Read in order, or choose your entrypoint. If someone sent you a delivery ZIP, start at step 4; you do not need to install the accelerator. If your team has already set it up, verify the active installation in step 5 and move to step 6.

Each lesson ends with an observable checkpoint. The example uses synthetic materials; generated files, a completed lesson and passing local checks do not establish production readiness.

## What to expect

You will see migration-wide planning, a detailed Billing domain, warehouse code and Omni model files, review decisions, and the path toward dashboard migration and release. One domain is a business area with related entities, rules, metrics and reports. It is not limited to a single question.

The PDF contains the same six lessons as these pages, with Omni typography and print layouts. GitHub controls the surrounding page fonts and colors. Both formats retain the distinction between illustrative diagrams, existing synthetic artifacts and live validation.
